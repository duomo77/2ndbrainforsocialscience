# writing/

## Purpose
The `writing/` directory provides AI-assisted academic writing tools. It supports the entire writing workflow from outline to final draft, with specialized support for social science writing conventions.

## Responsibilities
- AI-assisted section drafting and revision
- Reference management and citation formatting
- Academic style and tone checking
- Collaborative editing support
- Export to target formats (LaTeX, Word, Markdown, PDF)

## Expected Contents
```
writing/
├── drafts/              # Writing draft management
├── templates/           # Document templates (paper, proposal, report)
├── sections/            # Section-by-section writing assistants
├── references/          # Reference and citation management
├── style/               # Style guides and compliance checking
├── review/              # Self-review and revision suggestions
└── export/              # Output format converters
```

## Future Expansion
- Journal-specific formatting templates
