# 한국어 정책논문 개정 기록

이번 개정은 GitHub `duomo77/2ndbrainforsocialscience`의 커밋 `e61e7254b274a1529159d6214693038973147ff6`에서 직접 내려받은 파일을 기준으로 한다. 저장소의 현재 파일을 ZIP 내부 파일과 Git blob 해시로 대조해 변경 파일도 반영하였다. 원자료와 기존 분석용 CSV는 수정하지 않았다.

## 추가한 내용

- 기본 양부모 해외 출생 비중 패널을 재현하였다. 계수 6.696774, 지방정부 43개, 관측치 126개다.
- 귀무가설을 부과한 wild cluster bootstrap-t 검정을 9,999회 시행하였다. 지방정부별 Rademacher 부호, CR1 재추정, 난수 시드 20261113을 사용했다. 양측 p=.0138, 몬테카를로 표준오차 약 .00117이다.
- 전년도 말 인구비중을 사용한 2023–2024년 패널을 추가했다. 동일 41개 지방정부·82개 관측치에서 시차 비중 계수는 9.7825, 95% 신뢰구간 [−8.3531, 27.9181], p=.2822다. 동일 표본의 당해 연도 비중 계수는 5.1876, 신뢰구간 [−8.9338, 19.3089], p=.4622다.
- 51개 지역에서 2022–2024년 부모배경 비중 변화를 분자와 분모로 정확하게 분해했다. 분자 증가와 분모 감소를 같은 현상으로 해석하지 않도록 보강했다. 이 분해는 이동·출생의 원인을 식별하지 않는다.
- 논문 6.1절, 7.4절, 9.5절과 부록 C를 추가했다. 추론 방식, 측정시점, 영향력과 비율 변화의 경로, 실행 가능한 시범사업 평가 규칙을 설명한다.
- 6개 모형의 추정치와 95% 신뢰구간 비교 그림, 동일 표본 측정시점 비교 표를 추가했다. 기존 형식과 편집 가능한 Word 수식을 보존했다.

## 무엇이 유지되는가

기본 패널의 양의 관계는 단일 지방정부 제외 및 추가 군집 부트스트랩에서 유지된다. 그러나 균형패널과 대도시권별 연도 효과를 동시에 적용하거나, 영향력이 큰 여러 지역을 함께 제외하면 정밀성이 떨어진다. 연간 차분과 시차 모형도 정밀하지 않다. 따라서 모든 민감도를 통과한 보편적·인과적 효과라고 결론 내릴 수 없다. 시차 모형의 약한 정밀성은 분석기간 단축과 함께 해석해야 한다. 부트스트랩도 시간가변 교란과 지역 간 오차 상관을 해결하지 않는다.

현재 결과는 지방정부 평균 조사기간의 관계다. 개인 이주배경 아동의 보호 지연, 가정폭력 사건의 처리기간이나 시설 배치 대기를 측정하지 않는다. 실제 Z 자료를 새로 확보하지 않아 IV/2SLS는 실행하지 않았다. 결측값을 대체하지 않았고 2025년 아동배경을 생성하지 않았다.

## 재현 명령

저장소의 `sweden-child-protection` 폴더에서 실행한다. 분석에는 requirements.txt의 과학 계산 패키지, 문서에는 python-docx와 pypdf 등이 필요하다.

```powershell
python upgrade_analysis.py
python upgrade_figure.py
python verify.py
python paper/build_paper.py
powershell -NoProfile -ExecutionPolicy Bypass -File paper/export_word_pdf.ps1
python paper/qa_render.py
python paper/validate_paper.py
```

이 작업 환경에서는 문서 생성과 PDF 검증에 Codex 번들 Python을 사용했고, 통계 계산은 별도의 과학 계산 패키지가 설치된 Python을 사용했다. PDF 내보내기는 Microsoft Word COM을 사용하므로 Windows와 Word가 필요하다. `qa_render.py`는 Poppler를 필요로 한다. bootstrap p값은 영기울기 검정이며 부트스트랩 신뢰구간을 산출하지 않았다. 추가 분석의 p값은 탐색적이고 별도의 다중검정 보정을 적용하지 않았다. 그림의 구간은 각 원모형의 구간이다.

추가 분석 코드: `upgrade_analysis.py`, `upgrade_figure.py`. 검증 및 추가 표는 `results/upgrade_*`에 저장한다. 공식 출처·자료 취득 기록과 기존 재현 명령은 `ANALYSIS_README.md`와 `raw/`에서 확인할 수 있다. 이번 작업은 기존 공식 자료의 추가 분석이며 최신 통계를 다시 취득한 작업은 아니다.
