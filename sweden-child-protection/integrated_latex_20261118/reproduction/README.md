# VIND28 공식 원자료 재구축과 독립 DML-DID 재추정

두 번째 점검은 [SECOND_AUDIT_KO.md](SECOND_AUDIT_KO.md)에 수록했다. 폴드 배정만 10회 바꾸면 2026−2025년 계수는 모두 음수이며 8회 p<.05였다. 2026−2023년은 모두 비유의였다. 한 분할의 비유의를 신호 부재로 일반화하지 않는다. 이전 주 분석은 유지하고 이 추가 민감도를 함께 보고한다.

2026-11-18. **원래 실행 코드를 발견해 그대로 실행한 정확 재현은 아니다.** 로컬·연결 저장소·논문용 ZIP 검색에서는 그 코드를 찾지 못했다. `results/code_search_audit.json`에 검색 범위와 한계를 기록했다. 공식 원자료에서 표본과 결과를 재구축하고, 공개된 설계를 바탕으로 아래의 새 코드를 작성해 실제 실행했다. 기존 보고치에 맞추는 학습기·시드 탐색은 하지 않았다.

## 무엇이 일치했나

- SCB TAB4823의 2015년 관측 인구수로 계산한 전국 290개 시군 해외 출생 비중의 비가중 75분위는 **15.662790386208915%**다. 기존 경계와 일치한다. 전국 고비중 시군은 73개다.
- 2018–2023, 2025–2026의 8개 관측 시점에 Ja/Nej가 있는 장기표본은 **191개(고비중 51개·비교 140개)**다. 2025–2026 연결표본은 **263개(68개·195개)**다.
- 191개 시군의 충족 건수는 고비중 집단 17→31→27개, 비교집단 39→56→69개로 원고와 일치한다. 연결 전환표도 일치한다.
- 장기표본 포함/제외 지역의 2015년 중위소득 평균은 **308.203 / 299.400천 SEK**다. 기존 308.20 / 299.40과 일치한다. 이는 고비중/비교집단 평균이 아니라 표본 포함/제외 평균이다.
- 이러한 일치는 자료 구성의 확인이며 DML의 원래 학습기와 폴드가 같다는 증거는 아니다.

기존 점추정과 구간을 동일하게 재현하지 못했다. 모든 주 구간은 0을 포함한다. 원래 코드·학습기·하이퍼파라미터·폴드 배정이 확인되지 않아 차이의 원인을 하나로 귀속할 수 없다. 기존 추정이 틀렸다고 입증한 것도 아니다. 새로운 구현에서 그 유의성이 확인되지 않았다는 결과다.

기간마다 주 추정과 아홉 가지 대안, 총 10개 설정을 확인했다. 2025−2023 계수는 모두 양수(9.21~15.07)이지만 p<.05는 없었다. 2026−2025 계수는 모두 음수(−23.77~−13.73)이며 p<.05는 한 설정뿐이었다. 2026−2023은 −12.78~1.34로 부호도 일정하지 않았다. 이는 사전에 고정한 제한된 설정의 민감도이며 ‘모든 가능한 설정’에 대한 검증이 아니다. 민감도 검정에 다중검정 보정은 하지 않았다.

SCB data 요청은 위 라이브 메타데이터에 있는 실제 변수코드와 범주를 사용했다. 정확한 POST 본문·URL·UTC·상태·SHA-256은 `results/requests.jsonl`에 있다. XLSX 다운로드 기록은 `results/download_log.json`, 원본 체크섬은 `results/raw_checksums.json`에 있다. 브라우저는 XLSX를 Unsupported content-type(400)으로 표시했으나 Python의 같은 공식 URL 요청은 HTTP 200으로 성공했다. 본 다운로드에서 DNS 오류는 없었다.

Ja=1, Nej=0만 분석값으로 코딩했다. `..` 등 미응답을 0으로 바꾸지 않았다. 스톡홀름과 예테보리의 도시 집계 비율은 이진값으로 변환하지 않았다. Malmö의 중복 행은 `results/official_duplicate_rows.csv`에 보존했다. 같은 코드·연도에 일치하는 Ja/Nej가 있는 경우 이를 한 번만 채택했고, 충돌하는 이진 응답이 있으면 실행을 중단하도록 했다. 수치로 제공된 도시 집계와 이진 응답을 평균하지 않았다.

원래 2023–2025 개별 파일의 역사적 대조는 이번에 다시 실행하지 않았다. 현재 2026년 공개 파일의 역사적 응답을 사용했으며, 전 기간의 측정동등성이나 조직 경계가 완전히 검증되었다고 주장하지 않는다.

## 새 DML 구현

5개 기초 공변량만 사용한다. 고비중 판정에 쓰인 해외 출생 비율을 다시 설명변수에 넣지 않았다. 21개 주 라벨을 `numpy.default_rng(20261106)`으로 섞어 5개 평가 폴드(주 수 5/4/4/4/4)에 나눴다. 평가 주는 성향점수·결과 변화 모형의 학습에서 완전히 제외했다. 행 단위 폴드로 주를 나누지 않았다.

주 학습기는 RandomForestClassifier/Regressor, 각 300 trees, min_samples_leaf=8, max_features=1.0이다. 폴드 k의 학습기 random_state는 20261106+k다. 결과 보조모형은 학습 폴드 비교집단에서 두 시점의 변화 ΔY를 직접 회귀한다. 성향점수는 [0.05,0.95]로 제한한다. 이는 원래 코드에서 복원한 설정이 아니라 이번에 명시해 고정한 설정이다. 논문에 기록된 부트스트랩 시드를 원래 교차적합 시드였다고 주장하지 않는다.

정규화 점수는 DoubleML의 observational panel DID 문서와 같은 형태다: https://docs.doubleml.org/stable/guide/scores.html#difference-in-differences-models . D의 평균을 p, q=(1−D)e/(1−e), r=ΔY−g0(X)라 하면 θ=mean[(D/p−q/mean(q))r], ψ=−Dθ/p+(D/p−q/mean(q))r. Python으로 이를 직접 구현했으며 DoubleML 패키지 자체를 실행한 결과라고 보고하지 않는다.

표준오차는 주별 ψ 합의 제곱합에 G/(G−1)을 적용한 영향함수 군집 표준오차이고 자유도 20의 t 구간이다. 보조학습의 불안정성·수렴률 조건을 보장하는 것은 아니다. 원래 DR-DID/SDID의 실행과 주 부트스트랩은 재실행하지 않았다. 별도 비조정 DID의 새 구간도 같은 영향함수 방식이며 기존 부트스트랩 구간과 구분한다.

대안은 (i) 표준화+로지스틱(C=1)/Ridge(alpha=1), (ii) ExtraTrees(나머지 설정 동일), (iii) 네 추가 폴드/학습 시드 20261107–20261110, (iv) 절단 .01/.10, (v) 자본이득 제외 가처분소득이다. 시드 대안은 폴드와 학습기 난수를 함께 바꾸므로 순수한 폴드 효과와 분리하지 않는다. 세 기간의 변화 회귀는 각각 새로 학습하여 점추정이 정확히 가산적일 필요는 없다.

OOF 예측·행별 영향함수·정규화 비교집단 가중치와 폴드 주 목록을 `results/oof_*.csv`, `results/folds_*.json`에 모두 저장했다. 주 추정 비교집단 ESS는 54.79다. 성향점수 21개가 .05 아래여서 절단되었다. 이는 중첩을 개선했다는 보장이 아니며 절단 민감도를 별도로 확인했다.

## 실행

Python 3, numpy, pandas, scipy, scikit-learn, openpyxl, requests가 필요하다. 실행 환경의 실제 버전은 `results/environment.json`에 있다.

```powershell
cd <이 폴더>
python verify_execution.py
python build_data.py
python analysis.py
python finalize.py
python second_audit.py
python second_audit_report.py
```

이 순서는 전체 ZIP의 보존 원본을 사용한다. 첫 명령이 보존 원본의 SHA-256과 저장된 주 추정값을 확인한다. 공식 자료의 새 버전이 필요하면 별도 작업 복사본에서 `discover.py`, `fetch.py`, `get_scb.py` 순으로 수집한다. `discover.py`는 XLSX와 공개 저장소 목록을 갱신하며 SCB 스크립트는 같은 이름의 응답이 있으면 이를 사용한다.

자료 체크는 표본 수·정확 분류 경계·모든 기준 시점 충족 건수·포함/제외 소득 평균·도시 집계 분리를 검증한다. 수치 체크는 군집 누출 없음·유한 공변량·평균 0 점수·상수 보조모형에서 단순 DID 점추정과 표준오차가 일치함을 검증한다. 세 주 모형을 다시 적합하여 점추정·표준오차·구간·ESS가 1e-10 이내에서 일치함도 확인했다. 원본 SHA-256도 유지되었다. 이는 새 코드의 점검이며 원래 코드와의 일치 검증을 대체하지 않는다.

GitHub에는 검토용 코드·정제자료·결과를 개별 파일로 제공하고, 용량이 큰 공식 원본은 상위 폴더의 전체 ZIP 안 `reproduction/raw/`에 포함했다.

집단 분류는 정책 처치가 아니다. 추정값은 관측된 지역별 절차 응답의 조정 변화 차이이며 개별 이주 아동의 보호·등교 지연 또는 2024년 개혁의 인과효과가 아니다.
