# 통합 원고 전반 검수

## 그림을 본문에 넣은 뒤의 심사 검토

| 그림 | 확인한 근거와 최종 교정 |
|---|---|
| 1. 전국 지도 | 290개 시군의 코드를 확인했다. 시군 비가중 중앙값 11.78→14.65%와 20% 이상 시군 35→62개가 집계와 일치했다. 범례는 두 해에 공통이며 분모를 시군별 연말 주민으로 명시했다. |
| 2. 세 대도시권 | 26·13·12개 시군과 2024년 조사기간 관측 44개를 확인했다. Botkyrka의 해외 출생 주민 비중은 44.21%이며 조사기간 값은 미관측이다. 빗금과 권역 밖 연회색의 의미를 본문에 넣었다. |
| 3. 단면과 패널 | 동일한 40개 시군의 잔차에서 −0.105와 +6.555일/%p를 대조했다. 그림의 세로축을 통일하고 표의 40개 균형패널과 연결했다. 가로축은 두 모형이 이용하는 변동 폭이 달라 별도로 유지한다. |
| 4. VIND28 추이 | 191개와 263개 표본의 분모·충족률을 대조했다. 191개 패널을 구성할 때 제외한 2024년을 가로지르는 선을 끊었다. 263개 표본에서 고비중 집단의 충족 건수는 두 해 모두 35개였고 양방향 응답 전환은 각각 13건이었다. |
| 5. DML 민감도 | 2026년 대 2023년에는 분할별 추정치 9개가 음수, 1개가 양수였고 10개 구간 모두 0을 포함했다. 2026년 대 2025년에는 10개 추정치가 모두 음수였으며 개별 구간 8개가 0을 제외했다. 채운 원과 빈 원으로 구간의 0 포함 여부를 표시했다. |

2024년 개편은 두 집단에 적용되었다. 원고의 조정 비교는 사전 인구구성으로 구분한 두 집단의 응답 변화 차이를 보여 준다. 관측된 격차 축소에서 개편 효과를 분리하려면 반사실 추세와 다른 집단별 충격에 관한 근거가 추가로 필요하다.

이 개정은 이전 공개본의 초록, 방법, 결과 해석, 참조 문헌과 재현 절차를 대조했다.

- **초록의 표본 귀속 오류를 수정했다.** 고비중 집단의 17→31→27개는 191개 장기패널의 2023·2025·2026년 결과다. 263개 연결표본의 고비중 집단은 2025·2026년 각각 35개다. 연결표본의 격차는 15.57→3.78%p로 축소됐고, 비교집단의 충족 건수는 70→93개였다.
- **결측의 함의를 명시했다.** 공식 응답에서 288개 이진 비교 대상의 경계를 다시 구했다. 2025년 하한 11.99%p가 2026년 상한 5.08%p보다 커, 결측에 대한 모든 이진 응답 가정에서 2025년 이후 축소가 유지된다. 2026년 자체의 격차 경계는 −2.32~+5.08%p다. 장기패널에서 그해 고비중 집단이 높았다는 관측과 분석 모집단 전체에 대한 판단을 구분했다.
- **CASE 1의 관측 규모에서 계수를 해석했다.** 2024년 기본 단면 회귀 4개와 패널 고정효과 회귀 4개를 보존 데이터로 다시 적합했다. 표의 계수, 95% 구간과 p값이 표시 정밀도 내에서 일치했다. 같은 40개 시군을 사용한 패널에서 양부모 해외 출생 비중의 잔차 표준편차는 약 0.268%p이고, 이 변동에 6.555일/%p를 적용하면 약 1.76일이다. 이는 관측 규모에서의 선형 환산이다.
- **VIND28 산식과 비교 기준을 명확히 했다.** 공식 2026년 설명의 서면 절차, 책임 있는 조직 수준, 최근 24개월 점검 또는 신설 예외를 명시했다. 사회청의 전국 공표치와 논문 분석표본의 집단별 비율을 구분했다. [사회청 공식 지표](https://www.socialstyrelsen.se/statistik-och-data/oppna-jamforelser/socialtjanst/vald-i-nara-relationer/)
- **추론 범위를 확인했다.** 주 DML 구간은 세 기간 모두 0을 포함한다. 추가 분할에서 2026−2025년은 모두 음수이고 8/10만 5% 수준에서 유의했다. 원래 실행 코드와 정확한 폴드 구성은 확보하지 못했다. 21개 주를 이용한 민감도 결과는 집계 절차 응답의 변화 차이를 보여 준다. 정책이나 이주배경의 인과효과, 개인 아동의 보호 지연을 주장하려면 별도 식별과 자료가 필요하다.
- **재현 시작 순서를 수정했다.** 보존 원본이 있는 ZIP에서 먼저 체크섬과 주 추정을 확인하도록 안내한다. 신규 다운로드는 별도 작업 복사본에서 다룬다.

검증 코드는 `verify_manuscript.py`에 있으며 기존 계량 결과 파일을 변경 없이 읽는다. 원자료와 저장된 결과 파일의 보존은 기존 체크섬에서 확인했다.
