# VIND28을 출발점으로 삼은 서술 개정

이번 개정은 통계 추정치를 바꾸는 작업이 아니라 논문의 질문과 서술을 정리한 작업이다. 기본 버전은 GitHub 커밋 `9ece53e774b708f98421e32a002b2802ece29a58`이다.

서론은 선행 원고가 VIND28로 다룬 교육보장 절차에서 시작한다. 절차가 마련되어 있다는 응답이 아동의 실제 지원 경험까지 설명하는지 묻고, 그 질문 가운데 현재 자료로 살펴볼 수 있는 조사기간을 분석하는 흐름으로 바꾸었다. 이주배경 비중과 처리기간이 관련될 수 있는 이유를 설명한 뒤 지역 간 비교와 지역 내 변화의 결과를 차례로 제시한다. 결론과 정책 제안도 실제 지원 개시일과 학교 복귀일을 확인해야 한다는 처음의 질문으로 연결하였다.

읽는 사람이 분석을 따라갈 수 있도록 문장을 다듬었다. 추상적인 표현과 같은 한계의 반복을 줄이고, 방법을 먼저 나열하기보다 왜 그런 비교를 했는지를 설명하였다. 숫자, 표, 신뢰구간과 탐색적 분석이라는 성격은 유지했다.

## 근거와 해석의 범위

- VIND28이라는 명칭과 선행 분석의 존재는 사용자가 제공한 통합 원고에 근거한다. 해당 원시 패널이나 선행 DID를 이번에 재추정하지 않았다.
- 교육보장 절차의 내용은 Socialstyrelsen의 공식 2019년 지표 설명 80번, 110–111쪽에서 확인했다. 이 문서는 코드 VIND28의 연도별 대응표를 제공하지 않으므로 역사적 지표의 코드와 측정동등성을 새로 인증한 것은 아니다.
- 서론의 2024년 34%는 Socialstyrelsen의 `Individ- och familjeomsorg – Lägesrapport 2025`, 39·43쪽과 표 5의 전국 공표값이다. 이번 51개 지방정부의 충족률이나 아동의 서비스 이용률로 사용하지 않았다.
- 참고 확인한 2026년 현황보고서는 32쪽 표 3에서 2024년 34%, 2025년 41%를 제시하지만 15쪽 요약에는 41%의 연도를 2024년으로 적고 있다. 이 내부 불일치 때문에 본문 수치는 2025년 보고서의 2024년 공표값을 근거로 삼았다. 원본은 확인 경로를 보존하기 위해 함께 저장했다.
- VIND28과 U33401의 대상과 결과는 다르다. 이번 개정은 두 지표를 결합한 회귀, 절차의 효과 또는 보호시설 동반 아동의 대기기간을 새로 추정했다고 주장하지 않는다.
- 기존 분석용 CSV와 회귀 결과 CSV, 부트스트랩 결과 등은 변경하지 않았다. 공식 배경자료 PDF 세 개와 요청 기록, 출처·체크섬 기록을 추가했다.

## 문서 재생성

기존과 같이 `python paper/build_paper.py`를 실행하고 Windows Microsoft Word에서 `paper/export_word_pdf.ps1`로 PDF를 출력한다. `paper/qa_render.py`로 전체 페이지를 렌더링하고 `paper/validate_paper.py`로 문서 구조와 핵심 수치를 확인한다. 분석 전체의 실행 방법과 추가 실증분석 설명은 기존 README 및 UPGRADE_NOTES_KO.md에 있다.
